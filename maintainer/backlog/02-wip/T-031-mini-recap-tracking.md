# T-031 : Savoir quand placer le mini-récap

- **Créé le** : 2026-10-22
- **Constat** : test de T-018d (2026-10-22). `CLAUDE.md` demande un mini-récap « tous les 3 ou
  4 concepts », mais ni `learner/parcours.md` ni son modèle ne notent le dernier récap. Le prof
  neuf, à la validation du concept 8, a supposé qu'un récap avait eu lieu après le concept 5,
  d'après le découpage du journal.
  Test de T-036 (2026-10-23) : le prof neuf n'a pas fait le récap, faute de savoir dans
  `learner/parcours.md` quand avait eu lieu le dernier.
- **À faire** : décidé au tri (2026-10-23) : noter le récap dans la ligne de journal de la
  session (« mini-récap 6-8 »), dans `CLAUDE.md`.
- **Fini quand** : un prof neuf sait, depuis `learner/`, si un récap est dû.
