# T-055 : Définir comment le site demande un ajout au cours (fil rouge compris)

- **Créé le** : 2026-10-24
- **Parent** : T-050
- **Constat** : décisions du 2026-10-24 : le cours est la source du fond, tout nouveau contenu d'enseignement passe d'abord par lui, et le site emploie le fil rouge. Or l'agent qui édite le site (page, schéma, encadré) peut avoir besoin d'un fait, d'un exemple ou d'une phrase que le cours n'a pas, notamment dans `course/fil-rouge-velos.md` (tenu par le mainteneur, ses « faits fixés » ne se publient pas). Rien ne dit aujourd'hui comment le demander : l'agent écrit le contenu dans le site, ce qui a produit les encadrés et les phrases de T-054. Les deux dépôts sont séparés (cours privé, site public) et peuvent être édités par des sessions différentes.
- **À faire** : étudier et décider : où vit la demande (ticket dans le backlog du cours, liste dans le site, ou les deux) ; son gabarit (page et section visées, besoin, formulation ou fait proposé, élément du fil rouge sur lequel elle s'appuie) ; qui la traite et comment (tri de `maintenance` §2, arbitrage du fil rouge §3) ; ce que le site fait en attendant (rien publier de cet élément) ; comment l'agent du site atteint le dépôt du cours (chemin configurable, comme `check-alignment`) et que faire quand il est absent ; les contrôles à ajouter (empreinte de `fil-rouge-velos.md` dans `check-alignment`, noms d'acteurs et de sources des encadrés vérifiés contre le fichier). Piste : l'agent du site n'écrit rien dans le site, ouvre un ticket « demande du site » dans `00-proposed/` du cours, le cours le traite par un ticket de contenu, puis le site se réaligne par `check-alignment`, comme T-053. Mettre à jour T-050d (documentation et skill `align-with-course`) avec la décision, et `maintenance` si elle change le comportement de l'agent.
- **Fini quand** : la manière de demander un ajout au cours est décidée par le mainteneur, avec les options écartées ; T-050d est mis à jour en conséquence ; un ADR est écrit si la décision passe la règle de `maintenance` (§4).
